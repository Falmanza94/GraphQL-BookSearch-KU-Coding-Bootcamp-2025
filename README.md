# GraphQL Book Search Engine

## Description

This is a full-stack MERN application that allows users to search for books via the Google Books API, save favorite books and manage their reading list. This was originally built using RESTful API but has been revised to use GraphQL with an Apollo Server.

## Installation

This assumes you're cloning the repo and running locally.

1. Clone the repository:
```bash
    git clone https://github.com/Falmanza94/GraphQL-BookSearch-KU-Coding-Bootcamp-2025
```
2. Navigate to the server and install dependencies:
```bash
    cd server
    npm install
```
3. Build the TypeScript files:
```bash
    npm run build
```
4. Open second terminal for client:
```bash
    cd ../client
    npm install
    npm run dev
```
